# Curso de Redes · atividades interativas

Sites estáticos (HTML, CSS e JavaScript puros) com os exercícios, simulados, laboratórios e simuladores do Curso de Redes. Cada atividade tem a sua própria página e pode ser embutida no Notion.

Índice: https://vitorggc569.github.io/redes-interativo/

- `assets/`: motor das atividades (`app.js`, `gen.js`, `sims.js`, `validators.js`), biblioteca de cálculo (`lib.js`) e o estilo.
- `mNN/<atividade>/`: uma pasta por atividade.
- `_src/`: geradores em Python. `python3 _src/build.py` recria as páginas a partir do conteúdo do curso.
