import ipaddress as ip
redes = [ip.ip_network(f"10.1.{i}.0/24") for i in range(4, 8)]
print(list(ip.collapse_addresses(redes)))   # [IPv4Network('10.1.4.0/22')]
redes2 = [ip.ip_network("192.168.1.0/24"), ip.ip_network("192.168.2.0/24")]

Lab 6.4

caça aos erros

Encontre o erro em cada configuração: (a) PC 172.16.5.64/26 com gateway 172.16.5.1; (b) link R1-R2 em 10.0.0.0/30 com R1 = 10.0.0.1 e R2 = 10.0.0.4; (c) duas VLANs com 192.168.20.0/24 e 192.168.20.64/26; (d) interface com 192.168.4.255/24.

Resposta

(a) 172.16.5.64/26 é o endereço de rede do bloco 64 a 127, não pode ser host, e o gateway .1 está em outro bloco (0 a 63). (b) 10.0.0.4 está fora do 10.0.0.0/30 (0 a 3); deveria ser 10.0.0.2. (c) 192.168.20.64/26 está dentro do 192.168.20.0/24: sobreposição. (d) 192.168.4.255 é o broadcast do /24.
